# Медиа для README

Сюда кладутся картинки и видео. Что чем снимать:

| файл | что на нём | чем снять |
|---|---|---|
| `brain.png` | мозг по нейропилям | уже собран: `python tools/build_cloud.py`, затем офлайн-рендер |
| `stage.png` | сцена «муха работает в 1С» | `python tools/screenshot.py stage` |
| `lab.png` | лаборатория коннектома | `python tools/screenshot.py lab` |
| `fly.png` | муха в студийном свете | `python tools/screenshot.py cinema` |
| `home.png` | стартовая страница | `python tools/screenshot.py home` |
| `timelapse.mp4` | таймлапс работы мухи | см. ниже |

`python tools/screenshot.py` без аргументов снимет всё подряд. Инструмент открывает
страницу в отдельном окне Edge, ждёт отрисовки и снимает именно это окно. Рабочий стол
должен быть свободен: если поверх висит полноэкранная игра или видео, окно браузера
не выйдет на передний план, и снимок не будет сделан — это защита от того, чтобы
случайно не заснять чужой экран. Ручной запасной вариант: кнопка «кадр в PNG»
на странице или Win+Shift+S.

## Как снять таймлапс

1. Открыть `report/stage.html`, выбрать лабораторную, скорость ×4.
2. Записать экран: Win+G (игровая панель Windows) или OBS, область — окно браузера.
3. Прогон одной лабы занимает 40–90 секунд, это и есть готовый ролик.
4. Положить файл сюда как `timelapse.mp4` — в README он уже прописан.

Для ролика «муха в студии» — `report/cinema.html`: слева она думает, поправляет
очки и печатает по кругу, справа вращается мозг.
