# Медиа для README

Сюда кладутся картинки и видео. Что чем снимать:

| файл | что на нём | чем снять |
|---|---|---|
| `brain.png` | мозг по нейропилям | уже собран: `python tools/build_cloud.py`, затем офлайн-рендер |
| `stage.png` | сцена «муха работает в 1С» | открыть `report/stage.html`, снять Win+Shift+S |
| `lab.png` | лаборатория коннектома | открыть `report/lab.html`, Win+Shift+S |
| `fly.png` | муха в студийном свете | `report/cinema.html`, кнопка «кадр в PNG» |
| `timelapse.mp4` | таймлапс работы мухи | см. ниже |

## Как снять таймлапс

1. Открыть `report/stage.html`, выбрать лабораторную, скорость ×4.
2. Записать экран: Win+G (игровая панель Windows) или OBS, область — окно браузера.
3. Прогон одной лабы занимает 40–90 секунд, это и есть готовый ролик.
4. Положить файл сюда как `timelapse.mp4` — в README он уже прописан.

Для ролика «муха в студии» — `report/cinema.html`: слева она думает, поправляет
очки и печатает по кругу, справа вращается мозг.
